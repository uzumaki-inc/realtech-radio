# #9 エンジニアに頼らない配信は難しかった｜「ノールック公開」事件と、分からないことへの向き合い方

## 💡 エピソード概要

セットアップは意外とうまくいったものの、その後「ノールック公開」事件が発生ーー前編・後編（#7 / #8）で語った「エンジニアに頼らないPodcast配信」を、実際に非エンジニアの編集メンバーが動かしてみた振り返り回。"分からないことが分からない"という心理的な壁との向き合い方を語ります。

- セットアップ（オンボーディング）は意外と好評だったが、その後事件発生。確認ステップを飛ばして、Claude Code がいきなり公開（デプロイ）。編集メンバーは一気に不安に
- "分からないことが分からない"が心理的ブロックになる。守備範囲の外に出れば誰でも同じで、AI時代は「知らないことの詳細」に触れる機会が増えている
- AIを使いこなすカギは「ディレクション力」と「スキル化」。最初は手動より遅くても、次から一瞬で終わる成功体験が扉を開く
- 個人でAIに課金している人は1%未満。食わず嫌いをやめて一度トライするだけで、じつは"上位5%"
